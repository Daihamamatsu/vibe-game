# vibe-game

Three.js を使用した 3D RPG ゲームです。
HTML / CSS / JavaScript のみで構成し、ビルドツールは使用しません。

## 特徴

- ブロック風ヒューマノイドのプレイヤーを矢印キーで自由に移動(向き付け・歩行モーション付き)
- 障害物との衝突判定(箱のバウンディングボックス交差判定)
- パトロールする敵キャラとの接触ダメージ・ノックバック・無敵時間
- HP システム(減った分だけバーが減少、0 でゲームオーバー)
- **浮遊島フィールド**: 島からはみ出すと落下し、ある高度まで落ちるとゲームオーバー
- ゲームオーバー画面と R キーによるリスタート(HP・位置・落下状態・敵をまとめてリセット)

## 実行方法

ビルド手順はありません。ファイルを HTTP サーバーで配信し、ブラウザで開くだけです。

> **注意**: Three.js を CDN (jsDelivr) から読み込むため、実行時には**インターネット接続**が必要です。

1. ローカルサーバーの起動前に使用ポートが空いていることを確認します(既定の開発ポートは `8085`)。

   ```sh
   netstat -ano | grep -i listening
   ```

2. 任意の静的サーバーを起動します(例: Python)。

   ```sh
   python -m http.server 8085
   ```

3. ブラウザで <http://localhost:8085> を開きます。

対象ブラウザ: 最新 Chrome / Firefox / Edge

## 操作方法

| キー | 動作 |
| --- | --- |
| ↑ ↓ ← → | プレイヤーを移動 |
| R | リスタート(いつでも可能。HP・位置・落下状態・敵を初期化) |

## ゲーム内容と仕様

プレイヤーは 10×10 ユニットの浮遊島の上を動き回り、島に配置された敵と障害物に注意しながら生存を目指します。

| 項目 | 値 |
| --- | --- |
| プレイヤーの移動速度 | フレームあたり 0.1 |
| 最大 HP | 100 |
| 敵キャラ(接触ダメージ) | 1 回 10 |
| ダメージ後の無敵時間 | 1 秒 |
| ノックバック距離 | 1.2 ユニット(敵から離れる方向) |
| 敵のパトロール | z = -1.5 の線上を x = -2.5 〜 2.5 往復(速度 0.03/フレーム) |
| 障害物 | 赤い 1×1×1 の箱 4 個(島中心から ±3 の位置) |
| 浮遊島のサイズ | 10×10 ユニット(端からはみ出すと落下開始) |
| 落下 | 重力 0.008/フレームで落下、y = -25 まで落ちるとゲームオーバー |
| 背景 | 水色(空色) |

## 技術スタック

- HTML / CSS / 純粋な JavaScript(TypeScript・ビルドツールなし)
- [Three.js](https://threejs.org/) **0.152.2**(jsDelivr CDN から読み込み。バージョンは固定)
- 外部 3D モデル不使用(プレイヤー・敵・島はいずれも箱・円錐のプリミティブで構成)

## プロジェクト構成

```
index.html   # ページ本体と UI(HP バー、ゲームオーバー画面)
game.js      # ゲームロジック(Three.js シーン、移動、衝突、敵、HP、落下)
.clinerules  # AI エージェント向け運用ルール
```

## 開発ワークフロー

- 変更は **Issue → ブランチ(`issue/N-キーワード`)→ PR** で進めます(1 Issue = 1 PR)
- コミットメッセージは Conventional Commits の type + 日本語の説明文 + Issue 番号の形式
  - 例: `feat: HP減少機能を追加 (Issue #8)`
- 新規の依存ライブラリは追加しません(Three.js のバージョン変更は事前に確認)
- 詳細なルールは [.clinerules](.clinerules) を参照
